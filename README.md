A dependency-free, single-pass reimplementation of makefun-site 1.0.0's static site builder — front matter, template dialect, Markdown subset and slug rule — that produces byte-identical output in about half the CPU time.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
